# Getting Started with AIDLC

See [GUIDE.md](../GUIDE.md) for the full developer guide.

This file is for quick reference once you're already set up.

## Quick Commands

```bash
# Install into a project
~/tools/aidlc/install.sh

# Set API key
export ANTHROPIC_API_KEY=sk-ant-...

# Run a skill
./aidlc run implement --requirement "Your task"

# List skills
./aidlc list
```
